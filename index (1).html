☁️ Google Drive
Para guardar tus datos en Google Drive necesitás tu propio Client ID gratuito (una sola vez):

1. Entrá a console.cloud.google.com y creá un proyecto.
2. Activá la Google Drive API.
3. En "Credenciales" creá un ID de cliente de OAuth tipo "Aplicación web".
4. En "Orígenes de JavaScript autorizados" agregá la URL desde la que abrís esta app.
5. Pegá acá el Client ID que te da Google.
⚠️ Esto no funciona abriendo el archivo directo desde tu computadora (file://). Necesitás subir esta app a un hosting con http/https (por ejemplo GitHub Pages, gratis).

🤖 Asistente financiero IA
Para usar el asistente necesitás tu propia API Key de Gemini, gratuita (una sola vez):

1. Entrá a aistudio.google.com/apikey.
2. Iniciá sesión con tu cuenta de Google.
3. Tocá "Create API key" (podés usar el mismo proyecto de Google Cloud que ya tenés, o uno nuevo).
4. Copiá la key que te genera y pegala acá abajo.
⚠️ Tu API Key queda guardada solo en este navegador (localStorage) y se usa para llamar a Gemini directamente desde la app. No la compartas ni la subas a un repo público.
